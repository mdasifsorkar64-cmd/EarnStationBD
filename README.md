# Earn Station BD

বাংলা-প্রথম, মোবাইল-উপযোগী স্বচ্ছ অ্যাফিলিয়েট আয়ের প্ল্যাটফর্মের ভিত্তি।

## বর্তমান অবস্থা
- প্রাথমিক responsive homepage তৈরি হয়েছে।
- কোনো ডিপোজিট, VIP প্যাকেজ বা নিশ্চিত আয়ের দাবি নেই।
- পার্টনার অনুমোদন, কনভার্সন ট্র্যাকিং এবং বৈধ পেমেন্ট ব্যবস্থা যাচাই না হওয়া পর্যন্ত আয়/উত্তোলন চালু নয়।

## ফাইল
- `index.html` — হোমপেজ
- `style.css` — মোবাইল-উপযোগী ডিজাইন
- `app.js` — ছোট স্ক্রিপ্ট

## পরবর্তী ধাপ
1. অনুমোদিত অ্যাফিলিয়েট আয়ের উৎস ও অনুমোদিত ট্রাফিক পদ্ধতি নিশ্চিত করা।
2. নিরাপদ নিবন্ধন, লগইন ও প্রকৃত কমিশন লেজার তৈরি।
3. অ্যাডমিন-পর্যালোচিত উত্তোলন আবেদন ও বৈধ bKash/Nagad পেমেন্ট ব্যবস্থা।
4. হোস্টিং ও প্রোডাকশন কনফিগারেশন।

API key, bot token, password বা payment credential কখনো Git repository-তে commit করবেন না।
